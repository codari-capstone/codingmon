# 다시 쓰기

같은 제출로 앞서 만든 리뷰가 아래 규칙을 어겨 학습자에게 보여 주지 못했다. 처음부터 다시 쓴다. 이번에도 어기면 학습자는 리뷰를 받지 못한다.

{{violations}}

다시 쓸 때는 다음을 반드시 지킨다.

- 코드는 한 글자도 쓰지 않는다. 다시 작성한 코드, 고친 줄, 함수 호출이나 선언 모양 대신 무엇을 어떻게 바꾸면 좋은지 말로 설명한다(예: "질의를 받기 전에 리스트를 한 번 정렬해 두고, 질의마다 위치만 찾는 방식").
- 함수·메서드·변수 이름은 괄호 없이 이름만 쓴다(예: "sorted 함수", "변수 total"). 학습자 코드를 짚을 때는 줄 번호와 말로 짚는다.
- 위 지시의 나머지 규칙과 출력 형식은 그대로 지킨다.
