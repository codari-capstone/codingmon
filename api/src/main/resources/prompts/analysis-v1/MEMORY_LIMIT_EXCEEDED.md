## 메모리 초과

허용된 메모리보다 많이 썼다.

- 메모리 제한(`memoryLimitMb`)과 입력의 최대 크기로, 코드가 만드는 리스트·배열·문자열의 크기를 어림해 `guesses`에 쓴다(예: 원소 10⁸개 리스트).
- 재귀 호출의 깊이가 입력 크기만큼 커지는지, 반복 안에서 값을 계속 쌓아 두는지 본다.
- `hiddenTests.bySize`와 `largestFailed`로 큰 입력에서만 실패했는지 확인해 `facts`에 쓴다.
- 1단계는 가장 큰 자료구조의 크기를 세어 보게, 2단계는 모두 저장하지 않아도 되는 값이나 줄일 재귀를, 3단계는 필요한 값만 남기는 원리를 설명한다.
