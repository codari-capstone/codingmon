## 출력 형식이 잘못되었습니다

답의 내용은 맞았지만 띄어쓰기나 줄바꿈이 문제에서 요구한 모양과 다르다.

- 예제의 기대 출력과 실제 출력을 한 글자씩 비교해, 줄 끝 공백, 빠지거나 더해진 빈 줄, 숫자 사이 구분 문자, 마지막 줄바꿈 중 무엇이 다른지 `facts`에 쓴다.
- 차이가 보이지 않으면(예제는 통과) 출력 설명의 형식 조건과 코드의 출력 부분을 비교해 `guesses`에 쓴다.
- 1단계는 어느 줄 어느 위치를 비교할지, 2단계는 출력하는 줄의 구분 문자나 줄바꿈을, 3단계는 출력 설명이 요구하는 형식의 규칙을 설명한다.
