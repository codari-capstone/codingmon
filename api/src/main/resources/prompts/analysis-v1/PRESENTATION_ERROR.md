## 출력 형식이 잘못되었습니다

답의 내용은 맞았지만 띄어쓰기나 줄바꿈이 문제에서 요구한 모양과 다르다.

채점은 줄바꿈 문자(CRLF와 LF)와 출력 끝의 줄바꿈 한 개를 맞춘 뒤 비교한다. 이 두 가지만 다르면 통과이므로 원인으로 짚지 않는다.

- 판정이 출력 형식 오류인 예제가 있으면, 그 예제의 기대 출력과 실제 출력을 한 글자씩 비교해 줄 끝 공백, 빠지거나 더해진 빈 줄, 숫자 사이 구분 문자 중 무엇이 다른지 `facts`에 쓴다.
- 예제를 모두 통과했으면 예제 출력의 차이를 원인으로 쓰지 않는다. 비공개 테스트에서만 실패한 것이므로 출력 설명의 형식 조건과 코드의 출력 부분을 비교하고, 어떤 입력(가장 작은 입력, 값이 하나뿐인 입력 등)에서 모양이 달라질 수 있는지 `guesses`에 쓴다.
- 1단계는 어느 줄 어느 위치를 비교할지, 2단계는 출력하는 줄의 구분 문자나 줄바꿈을, 3단계는 출력 설명이 요구하는 형식의 규칙을 설명한다.
