# 다시 쓰기

같은 제출로 앞서 만든 답이 아래 규칙을 어겨 학습자에게 보여 주지 못했다. 처음부터 다시 쓴다. 이번에도 어기면 학습자는 분석을 받지 못한다.

{{violations}}

다시 쓸 때는 다음을 반드시 지킨다.

- 코드는 한 글자도 쓰지 않는다. 함수 호출, 변수 선언, 반복문·조건문의 머리처럼 코드에 그대로 옮겨 넣을 수 있는 글 대신, 무엇을 어떻게 바꾸면 되는지 말로 설명한다(예: "반복이 i가 0부터 n − 1까지 돌게").
- 학습자 코드를 짚을 때는 줄 번호와 말로 짚는다. 고친 뒤의 줄을 보여 주지 않는다.
- 개념 태그와 알고리즘 이름을 쓰지 않는다. 그 방법이 어떤 원리로 문제를 푸는지 풀어서 설명한다.
- 위 지시의 나머지 규칙과 출력 형식은 그대로 지킨다.
