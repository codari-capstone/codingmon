## 시간 초과

정해진 시간 안에 끝나지 않았다. 답이 맞는지는 확인하지 못했다.

- 제약에 나온 입력의 최대 크기로 반복이 몇 번 도는지 계산해 복잡도를 설명한다(예: n ≤ 100,000에서 이중 반복이면 약 100억 번). 계산은 `guesses`에 쓴다.
- `hiddenTests.bySize`와 `largestFailed`로 큰 입력에서만 실패했는지 확인해 `facts`에 쓴다.
- 끝나지 않는 반복(종료 조건이 바뀌지 않는 반복)일 가능성도 함께 본다.
- 입력을 한 줄씩 느리게 읽는 방식, 반복 안에서 매번 리스트를 새로 만들거나 처음부터 찾는 연산처럼 숨은 비용도 짚는다.
- 1단계는 입력이 가장 클 때 반복 횟수를 세어 보게, 2단계는 줄일 반복이나 반복 안의 연산을, 3단계는 같은 계산을 다시 하지 않고 줄이는 원리를 식으로 설명한다.
