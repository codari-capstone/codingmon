## 런타임 에러

실행 도중 프로그램이 멈췄다. `runtimeErrorType`이 멈춘 이유의 종류다.

- 에러 종류를 쉬운 말로 설명한다. 아래 영어 이름은 입력에서 알아보는 데만 쓰고 답에는 옮기지 않는다(괄호 안에도 쓰지 않는다): `INDEX_ERROR`는 리스트·배열에 없는 칸을 읽거나 쓴 것(C++의 잘못된 메모리 접근 포함), `ZERO_DIVISION`은 0으로 나눈 것, `VALUE_ERROR`는 값의 모양이 맞지 않아 변환하지 못한 것, `NAME_ERROR`는 만들지 않은 이름을 쓴 것, `TYPE_ERROR`는 서로 다른 종류의 값끼리 계산한 것, `RECURSION_ERROR`는 재귀 호출이 너무 깊은 것, `EOF_ERROR`는 주어진 입력보다 더 많이 읽으려 한 것, `OTHER`는 그 밖의 이유다.
- 예제의 `errorMessage`는 공개 예제에서 나온 원문이라 인용해도 된다. 비공개 테스트에서 난 에러는 `hiddenTests.runtimeErrorTypes`의 종류만 말한다.
- 그 에러가 날 수 있는 줄을 짚고, 어떤 입력에서 그렇게 되는지(가장 작은 입력, 경계값, 입력 줄 수 등)를 짐작으로 쓴다.
- 1단계는 에러 종류와 멈춘 위치를 확인하게, 2단계는 인덱스 범위·나누는 값·입력 읽는 방식·재귀 종료 조건 중 어디를 바꿀지, 3단계는 그 값이 안전한 범위에 머무는 조건을 식으로 설명한다.
