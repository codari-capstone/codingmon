## 틀렸습니다

끝까지 실행됐지만 어떤 입력에서 정답과 다른 값을 출력했다.

- 먼저 출력 형식 문제인지 로직 문제인지 가른다. 예제의 기대 출력과 실제 출력을 한 줄씩 비교해 다른 곳을 `facts`에 쓴다.
- 예제를 모두 통과했으면 비공개 테스트 요약에서 실패한 경우의 특성을 쓴다: 실패 개수, 크기 등급별 실패, 가장 작은 입력·가장 큰 입력에서 실패했는지.
  - 작은 입력에서 실패하면 경계값(0, 1, 빈 입력, 같은 값)과 빠뜨린 조건을 의심한다.
  - 큰 입력에서만 실패하면 자료형 범위를 넘는 값(예: 32비트 정수 넘침)과 반복 범위를 의심한다.
- 문제 조건 중 코드가 다루지 않는 것이 있는지 지문과 비교한다.
- 1단계는 무엇과 무엇을 비교할지, 2단계는 고칠 위치(조건식, 반복 범위, 식, 자료형, 출력 형식)와 방향, 3단계는 정답 출력이 나오는 규칙을 식과 말로 설명한다.
